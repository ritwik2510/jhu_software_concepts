# Module 12: NumPy Neural Network for Admissions Prediction

## What this program does
Loads GradCafe applicant data, filters and preprocesses it, and trains a two-layer
neural network to predict whether an applicant was Accepted or Rejected.
## Files included
- `neural_network.py` - full pipeline: data loading, preprocessing, model, training, evaluation, plotting, and artificial applicant testing
- `llm_extend_applicant_data_run.jsonl` - source dataset (JSON Lines)
- `training.log` - complete training log generated by the script
- `mse_curve.png` - training vs. test MSE plot generated by the script
- `README.md` - this file

## How to run
```powershell
python neural_network.py
```

No additional setup is required beyond having numpy, pandas, scikit-learn, and
matplotlib installed (Python 3.10+).

## Outputs produced
- Console output and `training.log`: dataset filtering counts, train/test split
  stats, training progress every 100 epochs, and final evaluation metrics
  (best epoch, best test MSE, final train/test accuracy)
- `mse_curve.png`: line plot of training and test MSE over epochs
- Table of predictions for two artificial applicants
